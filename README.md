# Lønpakken

En simpel værktøj til at beregne og sammenligne totale lønpakker på tværs af jobtilbud.

## Kom i gang

**Krav:** Node.js 18+

```bash
npm install
npm run dev
```

Åbn http://localhost:5173 i din browser.

## Byg til produktion

```bash
npm run build
npm run preview   # forhåndsvis produktionsbygget lokalt
```

Outputtet findes i `dist/` og kan deployes til enhver statisk host (Netlify, GitHub Pages, Vercel osv.).
